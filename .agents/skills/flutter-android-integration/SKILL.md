# Flutter → Android Integration (Add-to-App)

Reference implementation: this repo (`video_Downloader_launcher_v1`).
Host = native Android app (`:app`, Kotlin, Gradle KTS). Guest = Flutter module (`video_downloader/`).

> [!IMPORTANT]
> Agent rules for this workflow:
> - **Do NOT run build commands** (`gradlew assembleDebug`, `build`, `installDebug`). The user builds manually.
> - Verify every file path / API against the current code before editing.
> - Keep the native app as the **source of truth** for shared settings (language, remote config, onboarding).

## 1. Gradle wiring (source integration)

### 1.1 `settings.gradle.kts`

```kotlin
pluginManagement {
    repositories {
        google()
        mavenCentral()
        gradlePluginPortal()
    }
}

dependencyResolutionManagement {
    // MUST stay PREFER_SETTINGS. PREFER_PROJECT makes :app ignore these repos
    // and JitPack deps (e.g. com.github.Dimezis:BlurView) fail to resolve.
    repositoriesMode.set(RepositoriesMode.PREFER_SETTINGS)
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://jitpack.io") }
        maven { url = uri("https://storage.googleapis.com/download.flutter.io") } // Flutter engine artifacts
    }
}

rootProject.name = "HostApp"
include(":app")

// Link the Flutter module (generated by `flutter pub get` inside the module)
apply(from = File(settingsDir, "<flutter_module>/.android/include_flutter.groovy"))
```

> [!WARNING]
> Do not switch to `RepositoriesMode.PREFER_PROJECT` to silence Flutter plugin repo warnings.
> Symptom: `Could not find com.github.<x>:<y>` with **jitpack.io missing** from "Searched in the following locations".

### 1.2 `app/build.gradle.kts`

```kotlin
android {
    defaultConfig { minSdk = 27 }
}
dependencies {
    implementation(project(":flutter"))
}
```

### 1.3 Root `build.gradle.kts` (multi-drive Windows fix)

If the project is on `F:` and the pub cache on `C:`, AGP fails with
`this and base files have different roots`. Keep plugin build dirs local:

```kotlin
subprojects {
    if (name != "flutter" && name != "app") {
        evaluationDependsOn(":flutter")
    }
    if (project != rootProject && name != "app" && name != "flutter") {
        layout.buildDirectory.set(file("${projectDir}/build"))
    }
}
```

### 1.4 Before every Android build

```bash
cd <flutter_module>
flutter pub get        # regenerates .android/ and plugin registrant
```

## 2. Pre-warm a cached FlutterEngine (Application)

`app/src/main/kotlin/<pkg>/<App>Application.kt`

```kotlin
override fun onCreate() {
    super.onCreate()
    initFlutterEngine()
}

private fun initFlutterEngine() {
    try {
        val loader = io.flutter.FlutterInjector.instance().flutterLoader()
        loader.startInitialization(this)
        loader.ensureInitializationComplete(this, null)

        // FlutterEngine(context) AUTO-registers plugins.
        // Do NOT also call GeneratedPluginRegistrant.registerWith(engine)
        // (causes "plugin already registered" warnings).
        val engine = FlutterEngine(this)
        engine.dartExecutor.executeDartEntrypoint(
            DartExecutor.DartEntrypoint.createDefault()
        )
        FlutterEngineHelper.initEngine(this, engine)          // channels + ad factories
        FlutterEngineCache.getInstance().put(FlutterEngineHelper.ENGINE_ID, engine)
    } catch (e: Exception) {
        e.printStackTrace()
    }
}
```

## 3. Engine helper (MethodChannel + native ad factories)

Pattern: `app/.../ui/videodownloader/VideoDownloaderEngineHelper.kt`

```kotlin
object FlutterEngineHelper {
    const val ENGINE_ID = "my_flutter_engine"
    const val CHANNEL = "nativeChannel"

    fun initEngine(context: Context, engine: FlutterEngine) {
        registerAdFactories(context, engine)   // GoogleMobileAdsPlugin.registerNativeAdFactory(...)
        initMethodChannel(context, engine)
    }

    fun initMethodChannel(context: Context, engine: FlutterEngine) {
        MethodChannel(engine.dartExecutor.binaryMessenger, CHANNEL)
            .setMethodCallHandler { call, result ->
                when (call.method) {
                    "openNativeLanguageScreen" -> {
                        context.startActivity(
                            Intent(context, LanguageSelectionActivity::class.java)
                                .putExtra("from_settings", true)
                                .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
                        )
                        result.success(true)
                    }
                    else -> result.notImplemented()
                }
            }
    }

    // Native → Flutter push (language is owned by native)
    fun notifyLanguageChanged(code: String) {
        val engine = FlutterEngineCache.getInstance().get(ENGINE_ID) ?: return
        val normalized = if (code == "in") "id" else code
        MethodChannel(engine.dartExecutor.binaryMessenger, CHANNEL)
            .invokeMethod("changeLanguage", mapOf("languageCode" to normalized))
    }
}
```

Call `notifyLanguageChanged(selectedCode)` from the native language screen on Done.

> [!NOTE]
> Use the **application context** in the helper (engine outlives activities).
> Native ad factories need a `LayoutInflater`; `LayoutInflater.from(appContext)` works.

## 4. Show Flutter inside a native screen

### 4.1 As a page / fragment (launcher ViewPager2)

Layout `fragment_<name>_container.xml`:

```xml
<FrameLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/flutter_container"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:background="#FAFAFA" /> <!-- match Flutter scaffold color -->
```

Fragment:

```kotlin
class FlutterContainerFragment : Fragment() {
    override fun onCreateView(i: LayoutInflater, c: ViewGroup?, s: Bundle?) =
        i.inflate(R.layout.fragment_flutter_container, c, false)

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)
        if (childFragmentManager.findFragmentByTag(TAG) == null) {
            val fragment = FlutterFragment.withCachedEngine(FlutterEngineHelper.ENGINE_ID)
                .renderMode(RenderMode.texture)          // REQUIRED inside ViewPager2 / animated parents
                .transparencyMode(TransparencyMode.opaque)
                .build<FlutterFragment>()
            childFragmentManager.beginTransaction()
                .replace(R.id.flutter_container, fragment, TAG)
                .commitNowAllowingStateLoss()
        }
    }
    companion object { private const val TAG = "tag_flutter" }
}
```

Register it in the pager adapter (`createFragment(position)`), and set the initial page
after layout: `binding.viewPager.post { binding.viewPager.setCurrentItem(0, false) }`.

> [!CAUTION]
> `RenderMode.surface` inside `ViewPager2` / launcher windows with wallpaper/blur
> → **blank white page** (SurfaceView sits behind the window and does not follow page translation).
> `FlutterFragment.CachedEngineFragmentBuilder` has **no** `shouldAttachEngineToHierarchy(...)` — don't call it.

### 4.2 As a full-screen Activity

```kotlin
startActivity(
    FlutterActivity.withCachedEngine(FlutterEngineHelper.ENGINE_ID).build(context)
)
```
Declare `io.flutter.embedding.android.FlutterActivity` in `AndroidManifest.xml`
(or a subclass that overrides `configureFlutterEngine`).

## 5. Flutter side (`<module>/lib/main.dart`)

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();

  // Only what MyApp needs to build the first frame:
  try { await Firebase.initializeApp(); } catch (_) {}
  try { await SharedPrefService.init(); } catch (_) {}

  const channel = MethodChannel('nativeChannel');
  channel.setMethodCallHandler((call) async {
    if (call.method == 'changeLanguage') {
      final code = (call.arguments as Map)['languageCode'] as String?;
      if (code != null && code.isNotEmpty) {
        await SharedPrefService.setSelectedLanguage(code);
        Get.updateLocale(Locale(code));
      }
    }
    return null;
  });

  // START UI FIRST — never block runApp on ads/orientation/network.
  runApp(const ProviderScope(child: MyApp()));

  // Fire-and-forget after first frame:
  MobileAds.instance.initialize().timeout(const Duration(seconds: 5))
      .catchError((e) { debugPrint('ads init: $e'); });
  SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp])
      .catchError((e) { debugPrint('orientation: $e'); });
}
```

> [!CAUTION]
> `await MobileAds.instance.initialize()` (or any slow platform call) **before** `runApp`
> with a pre-warmed engine → Flutter never draws → white screen. Log stops after the last
> successful `await` and `runApp executed` never prints.

Rules for the Flutter module when embedded:
- Do **not** show its own splash / onboarding / language screen — native owns these.
- Open native screens via channel (`openNativeLanguageScreen`), not Flutter routes.
- Every translation key used in Flutter must exist for every language native offers.

## 6. Firebase / Remote Config in both apps

- One `app/google-services.json` (host package name) serves both native and Flutter
  (Flutter's `Firebase.initializeApp()` reuses the native default app).
- Keep each app's Remote Config under **one JSON parameter** and read its name from
  **one constant** (e.g. `RemoteConfigKeys.ROOT_KEY` in Kotlin and a single `const` in Dart),
  so renaming is a one-line change.

## 7. Verification checklist (manual — user runs builds)

1. `flutter pub get` in module → `.android/include_flutter.groovy` exists.
2. Gradle sync OK; no `Could not find com.github...` (JitPack reachable via settings repos).
3. Logcat filter `flutter`, expect in order:
   `main() started → Firebase initialized → SharedPrefService initialized → runApp executed → MobileAds initialized`.
4. No `Attempted to register plugin ... already registered` warnings.
5. Flutter page renders on first open and while swiping (no white page).
6. Change language natively → Flutter UI updates (`Updated locale to xx` in log).

## 8. Troubleshooting map

| Symptom | Cause | Fix |
|---|---|---|
| White/blank Flutter page, `runApp executed` missing | `await` before `runApp` hangs | Move non-essential awaits after `runApp` |
| White page, `runApp executed` present | `RenderMode.surface` in pager/wallpaper window | `RenderMode.texture` |
| `Could not find com.github...` (no jitpack in search list) | `PREFER_PROJECT` mode | `RepositoriesMode.PREFER_SETTINGS` |
| `Unresolved reference 'shouldAttachEngineToHierarchy'` | API doesn't exist on cached builder | Remove the call |
| `different roots: F:\... and C:\...` | Plugins buildDir across drives | Root `subprojects { layout.buildDirectory... }` |
| "plugin already registered" spam | Manual `GeneratedPluginRegistrant` + auto-registration | Remove manual call |
| Native ad factory not found in Flutter | Factories not registered on cached engine | Register in `initEngine` (Application) |
| Language mismatch between apps | Flutter owns its own language screen | Native is source of truth; push via `changeLanguage` |
